Présentation du projet

Gestion hospitalière réunit les patients, les médecins, les rendez-vous, les dossiers médicaux et les statistiques de consultations dans une seule application web sécurisée. Chaque utilisateur accède aux fonctions de son rôle : administrateur, médecin ou secrétaire.
